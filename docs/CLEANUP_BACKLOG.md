## Модальные окна

- **Формы админки** (роль, команда, участник команды, участник организации) держат «Отмена» и отправку внутри формы, а не в подвале окна (`footer` у `Modal`), как остальные окна. (2026-11-18)
- **Окна админки в браузере не проверены** после перевода на `Modal`: `/admin` требует входа, на `/demo/planner` их нет. (2026-11-18)
- **Системный `window.confirm`** при уходе с несохранённой интеграции трекера в админке (`useUnsavedIntegrationLeaveGuard.ts`) — единственный нативный диалог в продукте. (2026-11-18)
- **Подтверждение поверх открытого окна:** слой `modalConfirm` для этого есть; где именно `useConfirmDialog` вызывается из открытой модалки — не прослежено. (2026-11-18)
- **Цепочки окон** (меню → окно → окно полей перехода) по коду не видны — нужен список сценариев от продукта. (2026-11-18)

- **Учёт работы:** у задачи без истории статусов блок таймлайна — пустое место с подписью «No status data» высотой с поле. (2026-11-18)
- **Поля перехода** в браузере на `/demo/planner` не открывались — фикстура не даёт перехода с обязательными полями. (2026-11-18)

- **Обрезка фото:** «Отмена» или Escape в окне обрезки сбрасывает выбранную картинку целиком — черновик фото снова пустой, файл нужно выбирать заново (`TaskCardSwimlaneImageDraftEditor.tsx`, `revokeCropSource`). Ожидаемее оставить картинку без обрезки. (2026-11-18)
