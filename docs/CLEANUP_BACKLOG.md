- **Семь окон со своей оболочкой** вместо [`components/Modal.tsx`](../components/Modal.tsx): `SettingsModal`, `CreateSprintModal`, `AccountWorkModal`, `TransitionFieldsModal`, `AdminFormModal`, `TaskCardDisplayDialog`, `PlannerImageCropperDialog`. У них разные затемнение (40/60 % и 50/70 %), скругление (`rounded-lg` и `rounded-2xl`), тень и рамка. (2026-11-18)
- **Не закрываются по Escape** (в компоненте обработки нет): настройки, создание спринта, учёт работы, поля перехода. В браузере не проверено. (2026-11-18)

Сделать экраном внутри настроек; после этого слой `modalNested` в `constants/zIndex.ts` нужен только пикерам дат. (2026-11-18)
- **Системный `window.confirm`** при уходе с несохранённой интеграции трекера в админке (`useUnsavedIntegrationLeaveGuard.ts`) — единственный нативный диалог в продукте. (2026-11-18)
